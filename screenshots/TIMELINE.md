## Adding a snapshot

```bash
pnpm gallery
node scripts/timeline.mjs snapshot <slug> "<title>" "<what changed>"
```

Re-running `snapshot` with an existing slug replaces that entry. `node scripts/timeline.mjs import <commit> <slug> "<title>" "<notes>"` pulls a gallery that was committed earlier on the branch.
